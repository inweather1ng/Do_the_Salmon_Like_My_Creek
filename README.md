# Do the Salmon like my Creek?

## Live Demo!
Try out the app by running on your browser without installing anything 
**[Here](https://dothesalmonlikemycreek.streamlit.app)**



An interactive web application built with Streamlit and Plotly to monitor, analyze, and visualize critical water quality parameters for salmon in Dry Creek and beyond on a monthly basis. Instead of leaving water quality data locked inside large CSV files, this tool transforms raw measurements into accessible, easy-to-interpret graphs and reports—empowering nonprofits, students, and community members to evaluate local salmon habitat suitability.




## 🦅 Project Background
The inspiration for this app began with my water quality Eagle Scout service project. I organized a monitoring initiative for my local creek tracking **5 key physicochemical parameters** alongside **2 environmental DNA (eDNA) parameters**. All field data was collected under an official **Quality Assurance Project Plan (QAPP)** to ensure scientific reliability and usability. To make these findings accessible beyond spreadsheets, I built this free, open-source web application so everyone—from local kids to water quality experts—can explore and understand the health of their creek.



## ✨ Main Features
* **Interactive Water Quality Dashboard:** Gain immediate insights into the latest Dissolved Oxygen (DO) readings and key metrics, complete with a color-coded map showing each site's current health status.
* **Time-Series Interactive Parameter Plots:** View dynamic graphs for each monitoring site to observe how seasonal changes impact water quality over time.
* **Comparative Analysis Plots:** Compare seasonal trends across parameters to track differences between upstream and downstream sites.
* **Correlation Analysis:** Examine correlations between parameters at individual sites to see how environmental variables influence one another.
* **Automated Report Generation:** Generate clean, readable parameter reports for specific sites to export and share actionable data.




## Run locally
Follow these steps to run the tool on your machine:


### 1. Prerequisites
Make sure you have Python and git installed.

### 2. Clone the Repository
Clone this repository and navigate into the project folder:
```bash
git clone https://github.com/inweather1ng/Do_the_Salmon_Like_My_Creek.git
cd Do_the_Salmon_Like_My_Creek
```


### 3. Install Dependencies
Install the required Python libraries using pip:
```bash
pip install -r requirements.txt
```
### 4. Run this command:
```bash
streamlit run Home.py

```
## You are all set!
